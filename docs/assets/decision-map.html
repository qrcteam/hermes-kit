The Decision Map

Four moving parts, in plain English — what each one does, which you can skip, and what it costs to give one person an assistant that remembers them.

You're giving someone a text-message assistant that writes down what it learns into a folder of notes they own, backs that folder up, and can search it by meaning instead of by keyword.

Everything below is just which tool does which part of that sentence.

The four pieces

One paragraph each. If you only read one line per card, read “without it”.

Hermes

the agent you text

Mandatory

An open-source agent that runs continuously on their machine and connects to a Telegram bot, so they text it from their phone like a person. Unlike ChatGPT it doesn't start from zero every time — it reads a file describing who they are, and it reads their notes.

Cost
Free. It needs a model to run on — that's the $20 below.
Without it
You have a folder of notes and nobody to talk to.

The vault

the memory itself

Mandatory

A plain folder of markdown files — notes in a handful of buckets, one fact each, cross-linked. The whole point is that it's text in a folder. If Hermes vanished tomorrow, they'd still have a readable notebook. No lock-in, no export step.

Cost
Nothing.
Without it
The agent forgets everything between conversations. This is the piece.

Obsidian

the window onto it

Optional

A free app that opens that folder and makes it navigable. It's a viewer, not a writer — it does nothing to the system. It's how a human looks at what the agent knows, thinks “that's not right”, and fixes it.

Cost
Free.
Without it
Everything still works. You'd be opening .md files in TextEdit.

Pinecone

recall by meaning

Defer if needed

Keyword search for “plumber” only finds notes containing the word. Semantic search for “who did I hire for the bathroom?” finds the note saying “went with Ruiz for the Henderson re-pipe” — no shared words at all.

Cost
Free tier is genuinely enough for one person.
Without it
Search stays literal. Fine at 50 notes, frustrating at 500.

How a thought becomes a memory

The mechanism worth understanding before anything else: the agent proposes, and a separate program disposes.

Why the agent can't write

The safety argument

The vault is mounted read-only, and that's enforced by the operating system.

Hermes is a language model wired to tools, so it can be talked into things — a forwarded email or a web page can contain instructions. That's true of every agent, not a flaw in this one.

So the design assumes it will eventually try to do something wrong, and makes the damaging version impossible rather than forbidden. It isn't a rule the agent is asked to follow. It's a rule it cannot break.

Each person brings their own subscription. One credential can't be shared across four people without getting rate-limited, and it keeps the boundary clean — a paying client pays for her own agent. The unlisted costs are electricity and a machine that stays awake: Hermes has to be running to receive a text.

Three things worth separating

The names collide, and that's where most of the confusion came from.

Hermes Agent ≠ OpenClaw

Different projects, different people. You're running NousResearch's hermes-agent. Where course material says “OpenClaw”, mentally substitute.

Hermes ≠ Claude OS

Claude OS is a dashboard that displays stats from Hermes, the vault and Pinecone. It's a viewer. It isn't part of this stack and this kit doesn't touch it.

Hermes ≠ Claude Code

Claude Code is the developer tool you build with. Hermes is the assistant you text. Both read the vault; only one writes code. Mazíx, Diane and Doug get Hermes only.

What it isn't for

Say these out loud at handover, so expectations don't drift.

  • Not a task manager. It remembers; it doesn't nag. A morning digest is not the same thing.
  • Not a second brain you maintain. If someone has to curate it, they won't. Capture is automatic and messy on purpose.
  • Not private from the model provider. What they text goes to OpenAI or Anthropic like any other chat. The storage is theirs; the thinking isn't.
  • Not a replacement for their existing tools. Diane keeps Keap. This sits alongside.

Decide before you start

Four answers per person, written into their record before you touch a terminal. They run in this order because each one narrows the next.

  1. What machine?Mac follows runbook 02, Windows runbook 03. This decides everything about scheduling.
  2. What model subscription do they already have?ChatGPT $20 is the path of least resistance. If they have neither, that's a conversation before install day — not during.
  3. What are their buckets?Four or five life areas, in their words, not yours. Annoying to change later, because notes are already filed into them.
  4. What's the one job?One sentence. “Doug wants to know what he was working on.” It goes at the top of their SOUL.md and shapes every other decision.
