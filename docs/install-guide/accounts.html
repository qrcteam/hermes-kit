Accounts & Connections

companion to the install gate card

Hermes is four jobs wearing one trench coat: a doorway (how you reach it), a brain (the model that thinks), a memory (the vault + what makes it findable and unloseable), and hands (the things it can act on). Every account below serves one of those jobs. The minimum set makes it alive; the horizon list is what it can grow into.

The minimum

Six pieces. Three are free, one is the model subscription they already have or need anyway, and two aren't accounts at all. Check them off as they exist.

⚠ Whose account matters more than which account The model login and Pinecone belong to them — their email, their password. The vault repo can live on the operator's GitHub (that's the qrcteam pattern) but say out loud that you can read it: consent, not assumption. The one thing you never share across installs is a paid key quietly landing on somebody else's bill — if a loaner key gets things running today, write it in the gate card's deviation notes and swap it out later.

The horizon — what Hermes can connect to

Everything below is real, supported capability — not roadmap poetry. None of it is required on day one. Add a connection when the person keeps asking for the thing it does; a creative install (see people/mazix.md) wants capture and voice first and may never want half this table. That's correct, not incomplete.
